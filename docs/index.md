# danish

**Geometric donut engine for wavefront sensing.**

danish implements a fast, geometric model for out-of-focus ("donut") stellar
images used to measure wavefront aberrations in telescopes.  It is based on the
algorithm described in:

> Janish, R., *An algorithm for rapid measurement of aberrations in pairs of
> out-of-focus images*, 2012, MIT undergraduate thesis.
> <https://dspace.mit.edu/handle/1721.1/78543>
